# The Principles Mandala — source of truth, re-derived

**Status: SOURCE ARTIFACT.** Built 2026-07-29 at the Composer's instruction, immediately after the
Protocols mandala and by the same method: *"same method, then for principle, but I want you to do the
job, not based on previous mandala."*

**Why re-derive at all.** A principles edge set already existed — the `Connections:` line at the foot
of each entry in `principles_candidate.md`, transcribed verbatim from the 2026-07-27 Figma canvas.
That set was *inherited*, never checked. This file derives the links again from the principle
**bodies**, and then reports the difference. The inherited set is not deleted and not assumed
correct; it is treated as a claim with a check now standing behind it.

**How independence was enforced, since the two live in the same file.** The inherited lines cannot be
unseen once read, so independence is structural rather than willed: a script scans each entry's body
with its own `Connections:` line **excluded by construction**, and reports which other principles the
prose actually names. Command finds the candidates; judgement types them. That is the same division
of labour the Protocols mandala used, and the reason the derived set could come out smaller than the
inherited one — which it did, by a factor of nearly four.
