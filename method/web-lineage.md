## The dream that keeps returning

Since 1995 the industry has chased one dream: **create visually, get real artifacts.** Every generation rebuilds it — WYSIWYG editors, CMS page builders, no-code platforms, now AI agents. Attempt #4 is running. The eras below are what each attempt paid to learn.

## Six eras, six lessons

**1. First WYSIWYG (1995–2004) — FrontPage, Dreamweaver.**
The promise: design visually, code generated for free. The price: tag soup — nested tables, spacer GIFs, proprietary extensions; artifacts only the tool itself could maintain.
→ **A tool that hides the material produces artifacts only that tool can maintain.** Code treated as exhaust is lock-in by opacity.

**2. Web standards (1998–2006) — WaSP, Zeldman, CSS Zen Garden.**
Same HTML, infinite skins. This era *won* — because the first non-human readers (screen readers, search engines) forced semantics.
→ **Semantic structure is the durable layer; presentation is swappable.** The AI agent is only the newest non-human reader. Same rule, third consumer.

**3. The Flash detour (1996–2010).**
Total creative freedom, pixel-perfect motion — no semantics, no URLs, no accessibility, proprietary runtime. Died with the iPhone.
→ **Freedom bought by abandoning the open material dies with its host.**

**4. The CMS era (2001–2015) — Drupal, WordPress, Joomla, PrestaShop.**
Democratization worked: editors ≠ developers, themes + plugins. The failures: theme spaghetti, plugin conflicts, hacked cores dying at every update — and page builders reinventing WYSIWYG *inside* the CMS, same bloated output. The loop's first visible repeat.
→ **Extend, never fork, the shared foundation** ("never hack core"). And: every "no code needed" layer regenerates the bad-code problem one level up, unless the output material is first-class.

**5. Responsive (2010–2016) — Marcotte, Bootstrap.**
The fixed canvas died; "what you see" became many whats.
→ **Design is rules under constraints, not a fixed picture.** The seed of design systems.

**6. Systems & visual dev (2013–now) — Atomic Design, Figma, Webflow, tokens.**
WYSIWYG again — but the canvas now manipulates real layout concepts directly, and the artifacts improve accordingly. Figma code layers are the current bet.
→ **WYSIWYG works exactly to the degree the visual surface manipulates the true material.**

## The meta-lesson — the loop

The consumer of the discipline keeps changing — browsers, screen readers, search engines, now agents. **The discipline never does:** structure carries intent; the material stays first-class; foundations are extended, never forked; freedom outside the open material is mortal; design is rules, not pictures. Every era that forgot one of these paid the same price in new packaging.

When a new tool promises the dream again, the orchestra asks the lineage's one question: **does the visual surface manipulate the true material, or a picture of it?** That answer predicts the tool's whole future.
